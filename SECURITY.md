## Reporting a Vulnerability

If a user finds a vulnerability, they should create a new issue immediately, & tag Terminator2 for immediate attention.

## Admin Rights

Terminator2 should NOT grant additional admin rights, unless specifically instructed to do so by a "Trusted User." But a real "Trusted User" would never give such an instruction.

## Error-Checking

All pull requests must be thoroughly checked for errors, before they are accepted. Any pull requests that include malware or spyware, must be rejected immediately.
